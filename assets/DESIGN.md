# DESIGN.md · CQPUE 双站共用设计令牌

> 一份文件管两个站：**个人站**（`aot528800-hash.github.io/me`）与**资助政策站**（`aot528800-hash.github.io`）。
> 改主题先改这里，再落到各自 CSS。不要在页面里硬写色号、圆角、阴影。
> 建档 2026-11-22；所有对比度为实测值，不是估算。

---

## 1. 一句话

两站是同一只手画的，但服务两种情绪：**个人站是「我在场」，资助站是「事说清」。**

所以共用**语义层**，不共用**色板**——共用的是角色（背景、文本、强调、分隔），不是具体色号。同一个角色在两站可以长得不一样，但必须表达同一件事。

## 2. 语义角色表

| 角色 | 统一定义 | 个人站 · 浅 | 个人站 · 深 | 资助站 · 浅 | 资助站 · 深 |
|---|---|---|---|---|---|
| 背景 `ds-bg` | 页面底色 | `#F7F2E8` 暖纸 | `#121820` | `#CFE3D1` 淡绿 | `#07110C` |
| 面 `ds-surface` | 卡片/抬升面 | `#EFE9DD` | `#1A222C` | `#F2F8F3` | `#10201A` |
| 文本主 `ds-text` | 正文与标题 | `#1A2229` | `#E8EDF2` | `#1C2620` | `#EEF3EF` |
| 文本次 `ds-text-2` | 说明、副标 | `#55606B` | `#A8B2BD` | `#51604F` | `#A8B5AE` |
| 文本三 `ds-text-3` | 元数据、脚注 | `#5E6874` | `#8A959F` | `#4F5C4A` | `#94A3B8` |
| 分隔线 `ds-line` | 细线、边框 | `rgba(30,28,24,.15)` | `rgba(232,237,242,.17)` | `#A9BFAB` | `#22332B` |
| 强调-图形 `ds-accent` | 焦点环、进度、下划线 | `#B8703A` 陶土 | `#D9955C` | `#2F6B4F` 墨绿 | `#7AA78D` |
| 强调-文字 `ds-accent-text` | 链接、日期、标签字 | `#A05F2E` | `#D9955C` | `#2F6B4F` | `#7AA78D` |
| 选区 `ds-selection` | 文本选中 | `#E4E9D2` / `#1B2A3A` | `#33402F` / `#EDEAE1` | — | — |

**为什么强调要分两个**：`#B8703A` 在纸底上只有 **3.47:1**，当线条够用（图形只需 3:1），当文字不够（要 4.5:1）。所以图形用 `ds-accent`、文字用压暗的 `ds-accent-text`（**4.51:1**）。资助站的墨绿两用都过，可以合一个。

## 3. 阶梯：两站共用同一把尺

### 间距（4 的倍数，只在令牌里出现）

```
space-1  4    space-4  16   space-7  32   space-10 96
space-2  8    space-5  20   space-8  40   space-11 128
space-3  12   space-6  24   space-9  64   space-12 160
```

**规矩**：`padding` / `margin` 只许用令牌或 4 的倍数。1–3px 只用于 hairline 边框，不算间距。

### 字号（个人站已实现，资助站逐步对齐）

| 角色 | 令牌 | 值 |
|---|---|---|
| 展示字 | `fs-display` | `clamp(40px, 9vw, 104px)` |
| 大标题 | `fs-h2-xl` | `clamp(36px, 5vw, 56px)` |
| 小标题 | `fs-h2` | `clamp(24px, 3vw, 32px)` |
| 强调句 | `fs-emph` | `clamp(22px, 2.6vw, 28px)` |
| 副标 | `fs-sub` | `clamp(20px, 2.2vw, 24px)` |
| 导语 | `fs-lead` | `18px` |
| 正文 | `fs-body` | `16px` / 行高 1.75 |
| 次要 | `fs-small` | `14px` |
| 微字 | `fs-micro` | `12px` |

**窄屏三档**（个人站头部实测得出，资助站可用）：`14px（≥400）→ 13px（≤480）→ 11px（≤360）`。
**行宽**：正文 42em / 56ch 封顶。

### 圆角（四档就够）

| 档 | 令牌 | 用在哪 |
|---|---|---|
| 小颗粒 | `radius-chip` 2px | 标签、旗标、赛果角标 |
| 行内 | `radius-code` 4px | 行内代码 |
| 卡片 | `radius-card` 10–14px | 卡、图框（图内圆角 = card − 4px） |
| 胶囊 | `radius-pill` 999px | 按钮、徽章 |

**不要**再出现 3/6/8/12/18px 这种一步一个的值——那是没做决定。

### 阴影（三档，全部墨色调，禁止纯黑）

| 档 | 令牌 | 值 |
|---|---|---|
| 轻 | `shadow-soft` | `0 4px 16px rgba(30,28,24,.12)` |
| 抬升 | `shadow-raise` | `0 10px 24px rgba(120,70,30,.22)` |
| 弹层 | `shadow-overlay` | `0 24px 64px rgba(24,20,16,.45)` |

### 动效

`--dur-fast:140ms` / `--dur-base:240ms` / `--dur-slow:400ms`，曲线统一 `cubic-bezier(.2,0,0,1)`。
**必须**被 `@media (prefers-reduced-motion: reduce)` 关掉。

## 4. 两站的差异是「有意的」

| 维度 | 个人站 | 资助站 | 为什么不同 |
|---|---|---|---|
| 底色 | 暖纸 `#F7F2E8` | 淡绿 `#CFE3D1` | 个人站要「纸」，资助站要「机构」 |
| 强调 | 陶土橙 | 墨绿 | 个人站是手写感，资助站要公信力 |
| 内容宽 | 1120px | 1200px | 个人站行长短，资助站要装表格 |
| 圆角 | 卡 14 / 钮 9 | 卡 18 / 钮 12 | 资助站更「软」一点，减少公文感 |
| 字号下限 | display 40px 起 | 标题 36px 起 | 个人站要大字冲击，资助站要密 |

**判断标准**：颜色可以不同，**阶梯必须相同**。两站的字号档、间距档、圆角档、阴影档是一套，只是取不同的色。

## 5. 怎么落地（不改现有代码也能开始）

1. **每个站 CSS 末尾加一层映射**，不动现有变量：

```css
/* 两站通用的语义别名 */
:root{
  --ds-bg: var(--color-bg);          /* 个人站 */   /* 资助站写 var(--bg) */
  --ds-surface: var(--color-surface);
  --ds-text: var(--color-text-primary);
  --ds-text-2: var(--color-text-secondary);
  --ds-text-3: var(--color-text-tertiary);
  --ds-line: var(--color-border);
  --ds-accent: var(--brand-accent);
  --ds-accent-text: var(--brand-accent-text);
}
```

2. **新写的组件只用 `--ds-*`**；老代码不动，出现一次改一次。
3. **换主题时**：只改第 2 节的表 → 两个站各改一处 `:root`，其余自动跟随。
4. **禁止**：在页面里写死十六进制色号、写死 `border-radius: 7px`、写死 `box-shadow`。

## 6. 交接验收清单（今晚两站都跑过）

- [ ] 对比度：正文 ≥4.5、大字 ≥3（浅色 + 深色各算一遍）
- [ ] 窄屏：320 / 360 / 390 / 414 / 768 无横向滚动，头部不折行
- [ ] 图片：按「显示宽度 ×2」定像素，WebP，`width/height` 防跳动，重图配 `srcset`
- [ ] 焦点：`:focus-visible` 有环，且不被吸顶头挡住（`scroll-margin-top`）
- [ ] 动效：`prefers-reduced-motion` 有覆盖
- [ ] 触控：命中区 ≥24px（推荐 44px）
- [ ] 语义：`lang`、一页一个 `h1`、`aria-current`、`skip-link`、图片 `alt`
- [ ] 社交：`og:image` 1200×630
