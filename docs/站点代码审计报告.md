## 三、审计中确认"无问题"的项（抽查记录）

- **XSS**：`PolicyDetail.vue` 的 `v-html` 内容经 `DOMPurify.sanitize(marked.parse(...))`；`linkify.js` 只用 `createElement` + `textContent` 构建链接，无 innerHTML 拼接。
- **外发请求**：构建产物中 0 处 `XMLHttpRequest / WebSocket / sendBeacon`；外部域仅 `vuejs.org / www.w3.org / github.com`（文档与下载链接）。
- **依赖**：12 个依赖无统计/推送/广告 SDK；无硬编码密钥。
- **隐私**：localStorage 仅 4 个键（学习进度、搜索词、字号、日程视图），无身份字段；无 Cookie。
- **对比度**：正文达 WCAG AA（21.0:1 / 18.8:1 / 17.0:1）；次要文字 3.44:1 低于 AA，属既有设计取舍（已由检查以 INFO 记录）。
- **断网可用**：e2e 实测断网后仍渲染 21 条、搜索可用（纯静态 + 本地数据）。
- **构建可重复**：连续两次 `node scripts/build-site.mjs`，全站产物 SHA256 汇总一致。

## 五、残留风险与建议（不阻塞）

1. **未启用 CSP**：站内存在较多内联 `style`，如需 CSP 需改 hash/nonce 方案（收益中等，属加固项）。
2. **次要文字对比度 3.44:1** 低于 WCAG AA 正文标准；如需严格 AA 可把不透明度提到 0.78。
3. **Markdown 正文为作者可信输入**（无用户输入渲染路径），故未加额外 sanitize；若将来接入外部内容需补。
4. **测试依赖本机 Chrome 与安卓构建产物**：缺环境时现为 SKIP（exit 0/2），CI 上建议固定 Chrome 版本并在流水线中构建 APK。
